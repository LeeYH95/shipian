# 视频制作说明

先确定用途、语言、画幅和长度。用户要求整套发布素材时，可根据 GitHub 展示场景采用简短横版讲解，并说明所用默认值；若用户已选框架、音乐、图标或镜头方向，沿用其选择。

分镜必须对应真实用户工作流：先给价值，再展示核心动作和结果，最后给获取方式。每个镜头记录时段、可读标题、画面来源、运动、字幕和事实证据；核心信息落定后留出阅读时间。

产品界面优先用真实录屏或截图。截图运镜不能证明真实交互流畅；手工绘制、合成或生成的概念画面必须标明。需要演示鼠标行为时使用可控的演示数据，不能假造尚未实现的功能。

复用项目色彩、材质和字体。视频制作交给当前可用的专业能力；没有视频渲染能力时继续完成分镜与素材，明确 MP4 未生成，不把 HTML 预览称为成片。

音乐和音效核实可公开分发范围；只有成片使用权不等于能把原音频放进源码仓库。可使用本次制作的原创配乐，记录生成方式。不擅自使用无许可的流行音乐或克隆他人声音。

至少检查：文件可打开、时长与分辨率、字幕完整、帧首尾无黑场、内容无个人数据。带声音时检查音轨、响度和削波；抽取各场景中点与转场前后关键帧。视觉观感需要人审，自动检查只负责技术门槛。
